# Лабораторная работа 09 — учёт товаров

## Краткий отчёт

Программа обрабатывает пять товаров из задания, рассчитывает стоимость склада, среднюю цену, остатки и скидки.

## Выполнение по заданию

### 1. Товары

Создана структура `Product` и срез из пяти товаров. Для каждой позиции выводятся цена, количество и категория.

### 2. Расчёты

Функции рассчитывают стоимость склада, среднюю цену и находят самый дорогой товар. `map` считает позиции по категориям. Остаток меньше пяти и скидка определяются через `if`.

### 3. Результат

- Стоимость склада: 1 876 000 тг.
- Средняя цена: 95 400 тг.
- Самый дорогой товар: ноутбук, 350 000 тг.
- Мало на складе: ноутбук, монитор и наушники.
- Скидка: ноутбук — 315 000 тг, монитор — 76 500 тг.

## Запуск

В PowerShell из этой папки:

```powershell
go run .
```

Если команда не найдена, откройте новый PowerShell после установки Go.

## Вывод

Срез хранит товары, цикл проходит по ним, а отдельные функции выполняют расчёты. Скидка не меняет исходные цены.
